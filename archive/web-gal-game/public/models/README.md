# Models moved

The GalGame 3D models and PMX textures were moved out of the web archive to
`archive/galgame-assets/` to avoid keeping two copies.

- PMX source: `archive/galgame-assets/vodyanitsa-source/`
- GLB: `archive/galgame-assets/arcore.glb`

The archived web app is kept for historical reference only; to run it again,
copy the needed model folders back here (or mount them) and reinstall deps.
