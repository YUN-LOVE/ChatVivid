## 使用边界

- **RikkaHub**：AGPL-3.0。它的代码、图标、截图都不能直接进入 chatvv。我们只参考“聊天页怎么排、助手卡怎么做、输入区怎么放”。本仓库**不提交** RikkaHub 截图；本地研究图放在 `.tmp-ref/`（已 gitignore）或直接看原仓库。
- **大肥鱼**：同人角色，非 DeepSeek 官方；CC BY-NC-SA 4.0，非商业。App 内必须展示完整署名；商业分发前必须替换或取得授权。
- **Material 3 Expressive**：设计规范可参考；`m3_expressive` 是 MIT 第三方包；`dynamic_color` 是 Apache-2.0。
- **Flutter**：Material 3 的 Expressive 组件仍在补齐中（见 `material-3-expressive/NOTES.md`），所以不能假设“Flutter 自带全部 Expressive”。
